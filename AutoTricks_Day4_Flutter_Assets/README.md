# AutoTricks Day 4 Flutter Assets

Use the supplied AutoTricks logo for brand reference, but do not repeat the logo unnecessarily inside every screen.

## Key assets
- `brand/autotricks_logo_original.png` — source logo supplied by the project owner.
- `backgrounds/workshop_garage.png` — dark premium workshop environment.
- `illustrations/mechanic_repairing_car.png` — mechanic/workshop visual for the dashboard.
- `cars/car_hero.png` — hero car visual.
- `backgrounds/loader_garage_dark.jpg` — dark loading background.
- `cars/loader_car.png` — car visual for the loader animation.
- `reference/autotricks_flutter_ui_reference_board.png` — visual reference board for the complete app direction.

## Approved visual direction
Dark cinematic automotive UI. Mostly black/charcoal surfaces; orange is the primary action/accent; red is used for attention/danger; white/grey for readable content.

## Flutter usage
Copy these folders into `assets/` in the Flutter project. Add the paths to `pubspec.yaml`.
The assets are prototypes and should be optimized/compressed before production if necessary.

## Important
The public landing page is separate. This asset package is for the Flutter mobile app only.
